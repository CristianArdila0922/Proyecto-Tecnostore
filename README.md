# TecnoStore - Sistema de Gestión

## Descripción
Sistema de consola en Java para gestionar el catálogo de celulares, clientes, ventas y reportes de TecnoStore. 
Implementado con POO, JDBC, Streams y Patrones de Diseño.

## Entregables
- Modelo, Lógica, y Persistencia (CRUD básico y JDBC).
- Scripts de Base de Datos.
- Reporte TXT autogenerado.

## Ejecución
1. Ejecutar el script `tecnostore_db.sql` en MySQL.
2. Añadir el conector `mysql-connector-j` al Build Path de su proyecto.
3. Compilar y correr el archivo `Main.java`.
